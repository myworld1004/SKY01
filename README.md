# SKY01

## 🎮 네온 점퍼: 룰렛 & 스킨 러너

레이저와 드론을 피하고 별 코인을 모아, 회전 룰렛으로 9종의 스킨을 뽑는 네온 러너 게임이에요.

### ▶ 바로 플레이하기

**https://myworld1004.github.io/SKY01/**

### 📲 앱으로 설치하기

설치하면 바탕화면이나 홈 화면에서 바로 실행되고, 인터넷이 없어도 플레이할 수 있어요.

**PC 크롬 / 엣지**
1. 위 게임 주소를 엽니다.
2. 게임 화면의 **「📲 앱 설치」** 버튼이나 주소창 오른쪽의 **설치 아이콘**을 누릅니다.
3. **설치**를 누르면 끝이에요.

**안드로이드 크롬**
1. 위 게임 주소를 엽니다.
2. 오른쪽 위 메뉴 **⋮**를 누릅니다.
3. **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.

**아이폰 / 아이패드 사파리**
1. 위 게임 주소를 엽니다.
2. 아래쪽 **공유** 버튼을 누릅니다.
3. **홈 화면에 추가**를 누릅니다.

> 설치 버튼이 보이지 않으면 페이지를 한두 번 새로고침해 보세요.

### 🕹 조작 방법

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 2단 점프 | `Space` / `↑` | 화면 탭, 오른쪽 버튼 |
| 슬라이딩 (공중 드론 회피) | `↓` / `S` | 왼쪽 버튼 |

### 🎡 스킨 룰렛

- 달리면서 별을 먹으면 코인이 1개씩 쌓여요. 처음에는 30코인을 줘요.
- 룰렛 1회는 **10코인**이에요. 이미 가진 스킨이 나오면 **5코인**을 돌려받아요.
- 스킨은 일반 3종, 희귀 4종, 전설 2종이 있어요.
- 최고 점수, 코인, 보유 스킨은 브라우저에 저장돼요.
